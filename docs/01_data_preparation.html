3.1 Overview

This chapter documents the preparation of the analytical dataset used in the analyses. The workflow starts from the analysis input file, checks the response variables, restricts the data to socially monogamous species, defines population-level identifiers, and summarises the final dataset used in the Bayesian models.

3.6 Breeding system restriction

The main analyses are restricted to socially monogamous species. This restriction is important because EPP is defined relative to social pair bonds. EPP estimates are therefore not directly comparable across systems without stable social pair bonds, or across polyandrous, lekking, or non-pair-bonded mating systems.

3.7 Response variable checks

The response variable is the number of broods with EPP out of the total number of broods sampled. Records were retained for modelling only when brood counts were available, the total number of sampled broods was greater than zero, and the number of EPP broods did not exceed the total number of sampled broods.

Show code

3.9 Reference-population overlap

The overlap between reference identity (id_reference) and population identity (population_id) is checked directly from the model-ready dataset. This summary was used to evaluate whether reference identity and population identity represented sufficiently distinct grouping structures. Because population identity captures repeated observations from the same species-locality combination, it was retained as the primary repeated-observation grouping factor in the full environmental models.

Show code 
if (file.exists("data/processed/dat_model_phylo.rds")) {
  overlap_dat <- readRDS("data/processed/dat_model_phylo.rds")
} else if (file.exists("data/processed/dat_model.rds")) {
  overlap_dat <- readRDS("data/processed/dat_model.rds")
} else {
  overlap_dat <- read_csv("epp_data_June2026.csv", show_col_types = FALSE) %>%
    mutate(
      lat_round = round(as.numeric(lat), 2),
      long_round = round(as.numeric(long), 2),
      population_id = paste(scientific_name, lat_round, long_round, sep = "_")
    )
}

overlap_dat <- overlap_dat %>%
  mutate(
    id_reference = if ("id_reference" %in% names(.)) {
      as.character(id_reference)
    } else {
      as.character(id)
    }
  ) %>%
  mutate(
    population_id = as.character(population_id)
  ) %>%
  filter(!is.na(id_reference), !is.na(population_id))

population_overlap <- overlap_dat %>%
  group_by(population_id) %>%
  summarise(
    n_records = n(),
    n_references = n_distinct(id_reference),
    id_references = paste(sort(unique(id_reference)), collapse = "; "),
    .groups = "drop"
  )

reference_overlap <- overlap_dat %>%
  group_by(id_reference) %>%
  summarise(
    n_records = n(),
    n_populations = n_distinct(population_id),
    .groups = "drop"
  )

3.10 Environmental window correlations

The main environmental models use environmental values from the first breeding-season month. As a data check, we compared these values with the corresponding full-season summaries for temperature, precipitation, diurnal temperature range, and NDVI. Because the correlations were high, subsequent analyses use the first-month environmental values and do not treat full-season summaries as a separate predictor set.

Show code 
environment_window_pairs <- tribble(
  ~variable, ~first_month, ~full_season,
  "Temperature", "tmp_cru_C_first_month", "tmp_cru_C_full_season",
  "Precipitation", "pre_cru_mm_first_month", "pre_cru_mm_full_season",
  "DTR", "dtr_cru_C_first_month", "dtr_cru_C_full_season",
  "NDVI", "ndvi_first_month_median_30km", "ndvi_full_season_median_30km"
)

environment_window_correlations <- purrr::pmap_dfr(
  environment_window_pairs,
  function(variable, first_month, full_season) {
    keep <- complete.cases(dat_model[, c(first_month, full_season)])
    test <- cor.test(
      dat_model[[first_month]][keep],
      dat_model[[full_season]][keep],
      method = "pearson"
    )

    tibble(
      variable = variable,
      n_complete = sum(keep),
      pearson_r = unname(test$estimate),
      lower_95_ci = test$conf.int[1],
      upper_95_ci = test$conf.int[2]
    )
  }
)

environment_window_correlations %>%
  mutate(across(where(is.numeric), ~ round(.x, 3))) %>%
  knitr::kable()
variable n_complete pearson_r lower_95_ci upper_95_ci
Temperature 480 0.922 0.907 0.934
Precipitation 480 0.489 0.418 0.554
DTR 480 0.920 0.904 0.932
NDVI 461 0.808 0.773 0.837
