8.1 Overview

This chapter presents a confirmatory re-test of a previously reported interaction: the association between temperature anomaly and extra-pair paternity (EPP) was reported to become less positive with increasing absolute latitude. The earlier result came from a different dataset and non-phylogenetic linear mixed models. Here, the hypothesis is tested in the current beta-binomial phylogenetic framework. Only the two prespecified temperature-anomaly × absolute-latitude interactions are fitted; this is not an exploratory interaction search.

8.3 Model set

Confirmatory model Prespecified interaction Other covariates
Short anomaly × latitude tmp_short_anom_5yr_C_first_month_z * abs_latitude_z short precipitation anomaly, distance to coast, nest box, marker type
Long anomaly × latitude tmp_long_anom_1961_1989_C_first_month_z * abs_latitude_z long precipitation anomaly, distance to coast, nest box, marker type

Both models use a beta-binomial response, phi ~ 1, and the same population, non-phylogenetic species, and phylogenetic species random intercepts as the main models.

8.4 Short-anomaly interaction

Show code 
m_interaction_short_latitude <- brms::brm(
  brms::bf(
    n_epp_broods | trials(n_broods_sampled) ~
      tmp_short_anom_5yr_C_first_month_z * abs_latitude_z +
      pre_short_anom_5yr_mm_first_month_z + distance_to_coast_z +
      nest_box + marker_type + (1 | population_id) + (1 | species_nonphylo) +
      (1 | gr(species_phylo, cov = phylo_mat_fit)),
    phi ~ 1
  ),
  data = dat_fit, data2 = list(phylo_mat_fit = phylo_mat_fit),
  family = brms::beta_binomial(link = "logit", link_phi = "log"),
  prior = priors_mu, chains = 4, cores = 4, iter = 10000, warmup = 5000,
  control = list(adapt_delta = 0.99, max_treedepth = 15), seed = 1407,
  save_pars = brms::save_pars(all = TRUE)
)

8.6 Directional posterior test

The prespecified direction from the earlier analysis is a negative interaction coefficient. Accordingly, the table reports the posterior mean, 95% credible interval, and posterior probability that each interaction is below zero.

Show code

m_interaction_long_latitude b_tmp_long_anom_1961_1989_C_first_month_z:abs_latitude_z -0.02 -0.121 0.081 0.649

Neither confirmatory interaction was supported. The short-term interaction was \(-0.020\) (95% CrI \(-0.115\) to \(0.075\); posterior probability of a negative effect = 0.667), and the long-term interaction was \(-0.020\) (95% CrI \(-0.121\) to \(0.081\); posterior probability of a negative effect = 0.649). Thus, both posterior means point weakly in the previously reported direction, but the intervals are centred close to zero and include effects of either sign.

The posterior coefficient and its uncertainty therefore remain the primary evidence for the confirmatory interaction tests.

8.9.1 Observation-level Pareto-k audit

High Pareto-k values were inspected against latitude and study intensity, rather than only counted. Across the interaction analysis, none of the problematic observations belonged to the five best-studied populations and their median population record count was one. They therefore are not an artefact of a few intensively sampled European populations. Tropical records were overrepresented: they comprise 8.4% of the full frame but 22–40% of the high-k sets, depending on the matched model. Recurring observations included Ardea ibis at absolute latitude 22.5 degrees (observed EPP proportion 0.613; maximum k 1.206) and Spheniscus humboldti at 15.37 degrees (observed EPP proportion 0). This identifies sparse, biologically unusual low-latitude records as an important source of predictive difficulty.

## Overview

This chapter presents a confirmatory re-test of a previously reported interaction: the association between temperature anomaly and extra-pair paternity (EPP) was reported to become less positive with increasing absolute latitude. The earlier result came from a different dataset and non-phylogenetic linear mixed models. Here, the hypothesis is tested in the current beta-binomial phylogenetic framework. Only the two prespecified temperature-anomaly × absolute-latitude interactions are fitted; this is not an exploratory interaction search.

## Model set

| Confirmatory model | Prespecified interaction | Other covariates |
|---|---|---|
| Short anomaly × latitude | `tmp_short_anom_5yr_C_first_month_z * abs_latitude_z` | short precipitation anomaly, distance to coast, nest box, marker type |
| Long anomaly × latitude | `tmp_long_anom_1961_1989_C_first_month_z * abs_latitude_z` | long precipitation anomaly, distance to coast, nest box, marker type |

Both models use a beta-binomial response, `phi ~ 1`, and the same population, non-phylogenetic species, and phylogenetic species random intercepts as the main models.

## Short-anomaly interaction

```{r}
#| label: interaction-short-code
#| eval: false
m_interaction_short_latitude <- brms::brm(
  brms::bf(
    n_epp_broods | trials(n_broods_sampled) ~
      tmp_short_anom_5yr_C_first_month_z * abs_latitude_z +
      pre_short_anom_5yr_mm_first_month_z + distance_to_coast_z +
      nest_box + marker_type + (1 | population_id) + (1 | species_nonphylo) +
      (1 | gr(species_phylo, cov = phylo_mat_fit)),
    phi ~ 1
  ),
  data = dat_fit, data2 = list(phylo_mat_fit = phylo_mat_fit),
  family = brms::beta_binomial(link = "logit", link_phi = "log"),
  prior = priors_mu, chains = 4, cores = 4, iter = 10000, warmup = 5000,
  control = list(adapt_delta = 0.99, max_treedepth = 15), seed = 1407,
  save_pars = brms::save_pars(all = TRUE)
)
```

## Directional posterior test

The prespecified direction from the earlier analysis is a negative interaction coefficient. Accordingly, the table reports the posterior mean, 95% credible interval, and posterior probability that each interaction is below zero.

```{r}
#| label: interaction-directional
if (!is.na(directional_file)) kable(read_csv_safe(directional_file), digits = 3)
```

Neither confirmatory interaction was supported. The short-term interaction was
$-0.020$ (95% CrI $-0.115$ to $0.075$; posterior probability of a negative
effect = 0.667), and the long-term interaction was $-0.020$ (95% CrI $-0.121$
to $0.081$; posterior probability of a negative effect = 0.649). Thus, both
posterior means point weakly in the previously reported direction, but the
intervals are centred close to zero and include effects of either sign.

## LOO comparison with main-effects models

Each interaction model is compared only with its matching main-effects-only counterpart. Pareto-`k` diagnostics are reported separately and are not replaced silently by another method.

```{r}
#| label: interaction-loo
if (!is.na(loo_file)) kable(read_csv_safe(loo_file), digits = 2)
if (!is.na(pareto_file)) kable(read_csv_safe(pareto_file), digits = 2)
```

The main-effects-only models had slightly higher expected predictive accuracy
than their interaction counterparts (ELPD differences of 1.92 for the short
anomaly and 1.51 for the long anomaly, with the main-effects model as the
reference). These LOO comparisons are explicitly treated as approximate:
several observations had Pareto $k>0.7$ and each interaction fit had one
observation with $k>1$. The posterior coefficient and its uncertainty therefore
remain the primary evidence for the confirmatory interaction tests.

### Observation-level Pareto-*k* audit

High Pareto-*k* values were inspected against latitude and study intensity,
rather than only counted. Across the interaction analysis, none of the
problematic observations belonged to the five best-studied populations and
their median population record count was one. They therefore are not an
artefact of a few intensively sampled European populations. Tropical records
were overrepresented: they comprise 8.4% of the full frame but 22--40% of the
high-*k* sets, depending on the matched model. Recurring observations included
*Ardea ibis* at absolute latitude 22.5 degrees (observed EPP proportion 0.613;
maximum *k* 1.206) and *Spheniscus humboldti* at 15.37 degrees (observed EPP
proportion 0). This identifies sparse, biologically unusual low-latitude
records as an important source of predictive difficulty.
