12.1 Why fit a zero-inflated model when the zero PPC already passes?

This analysis implements the preregistered primary family without changing any of the existing main models. The diagnostic result preceding the refit is important: the standard beta-binomial PCA model observed 48 zero-EPP records but predicted a mean of 53.7 (95% posterior-predictive interval 41–66; posterior predictive probability of a count no larger than observed = 0.21). Thus the standard model already reproduces the zeros and, if anything, slightly overpredicts them. The zero-inflated fits below are retained because they were preregistered, not because the data show unexplained excess zeros.

Zeros also occurred mainly in small samples: the median sample was 11.5 broods for zero records and 23 for non-zero records, and no zero occurred above 50 sampled broods. This pattern is consistent with beta-binomial sampling variation. The raw marker contrast points in the registered direction but is not a controlled marker effect: DNA fingerprinting had 18.2% zero records and microsatellites 8.4%. Marker type is associated with study era and taxonomic composition, so these percentages are descriptive only.

12.2 Model specification and reproducibility safeguards

The PCA, short-anomaly, and long-anomaly mean models use zero_inflated_beta_binomial(link = "logit", link_phi = "log", link_zi = "logit"). Every other element is held fixed: the exact saved 441-row model frame, predictors, phylogenetic covariance, three random intercepts, four chains, 10,000 iterations (5,000 warm-up), adapt_delta = 0.99, and maximum tree depth 15. New seeds are 1601, 1603, and 1605.

The original priors_mu block was reproduced literally and automatically compared with the parsed assignment in the unchanged main-model script. This is an executable equality check rather than a manual assertion.

Show code

literal priors_mu versus parsed main-script priors_mu TRUE scripts/run_main_environmental_models.R

The additional zero-inflation intercept received a Normal(-2, 1.5) prior on the logit scale. Its prior median is 0.119 on the probability scale, while its width allows probabilities close to zero as well as appreciable inflation. Because a logit parameter maps continuously to the open interval (0, 1), its credible interval cannot literally include zero. Evidence against a needed structural-zero component must instead come from posterior concentration near zero, the zero-count PPC, and out-of-sample predictive comparison.

12.6 Predictive comparison

LOO was computed separately for each zero-inflated model and compared only with its standard counterpart fitted to the identical 441 observations. Initial PSIS-LOO estimates used moment matching. For the manuscript comparison, within each of the six fitted models, every observation with Pareto \(k > 0.7\) was then replaced by an exact leave-one-out refit (reloo). This required 41 refits in total: 21 for the standard models and 20 for the zero-inflated models. Each refit retained the original priors, formula, random effects, and sampler settings.

The standard beta-binomial was favoured in every matched comparison: the zero-inflated fits had exact-reloo ELPD differences of -3.12 (PCA), -4.03 (short anomaly), and -2.93 (long anomaly). Together with the passing zero-count PPC and the near-zero structural-zero posterior, this shows that the preregistered zero-inflation component is unnecessary for these data. Relative to moment matching, exact refitting made the zero-inflated-minus-standard ELPD difference more negative by 1.46, 2.23, and 0.30 ELPD units for the PCA, short-anomaly, and long-anomaly pairs, respectively; thus reloo strengthened rather than reversed the original conclusion.

Before exact refitting, each zero-inflated model had 6–8 observations above 0.7; the PCA and long-anomaly models each had one above 1. None came from the five best-studied populations, while tropical records were again more frequent among the flagged cases than in the full frame. These observations motivated reloo; after their pointwise contributions were replaced by exact leave-one-out estimates, no unresolved Pareto-\(k\) value above 0.7 remained in any of the six LOO objects used in the comparison.

This required `r if (models_ready) sum(reloo_diagnostics$n_exact_refits) else "pending"` refits in total: `r if (models_ready) sum(reloo_diagnostics$n_exact_refits[reloo_diagnostics$version == "standard"]) else "pending"` for the standard models and `r if (models_ready) sum(reloo_diagnostics$n_exact_refits[reloo_diagnostics$version == "zero_inflated"]) else "pending"` for the zero-inflated models. Each refit retained the original priors, formula, random effects, and sampler settings.
