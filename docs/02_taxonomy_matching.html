4  Taxonomy and phylogeny

5 Aim

This page prepares the taxonomic and phylogenetic structure used in the Bayesian comparative analyses.

The goal is to verify species matching between the analytical dataset and the phylogenetic tree, prune the tree to the species included in the study, generate a phylogenetic correlation matrix, and prepare the phylogenetic grouping variables required for the Bayesian models.

        "scientific_name",

        "family_common"
      )
    )
  ) %>%

  !"family" %in% names(dat_model) ||
    ("family" %in% names(dat_model) && all(is.na(dat_model$family)))

  dat_model <- dat_model %>%
    select(-any_of(c("order", "family", "family_common")))
}

needs_family_merge <- !"family" %in% names(dat_model) ||
  all(is.na(dat_model$family))

if (needs_family_merge && "epp_row_id" %in% names(dat_model)) {
  dat_model <- dat_model %>%
    left_join(
      dat_taxonomy %>%
        select(
          epp_row_id,
          any_of(c("order", "family", "family_common"))
        ),
      by = "epp_row_id"
    )
}

needs_family_merge <- !"family" %in% names(dat_model) ||
  all(is.na(dat_model$family))

if (needs_family_merge && "record_id" %in% names(dat_model)) {
  dat_model <- dat_model %>%
    left_join(
      dat_taxonomy %>%
        select(
          record_id,
          any_of(c("order", "family", "family_common"))
        ),
      by = "record_id"
    )
}

needs_family_merge <- !"family" %in% names(dat_model) ||
  all(is.na(dat_model$family))

if (needs_family_merge && "Clements_name" %in% names(dat_model)) {
  dat_model <- dat_model %>%
    left_join(
      dat_taxonomy %>%
        select(
          Clements_name,
          any_of(c("order", "family", "family_common"))

10 Prune the phylogeny

The full phylogenetic tree contains many species not included in the EPP dataset. Therefore, the tree was pruned to retain only species present in the analytical dataset.

Show code 
tree_pruned <- ape::drop.tip(
  tree,
  setdiff(tree$tip.label, species_data)
)

11 Generate the phylogenetic correlation matrix

12 Prepare phylogenetic grouping variables

Two species-level grouping variables were retained for the Bayesian models:

  • species_phylo - species identity linked to the phylogenetic covariance matrix;
  • species_nonphylo - species identity modelled as an additional non-phylogenetic random effect.

Including both random effects allows the models to partition variation attributable to shared evolutionary history and species-specific variation not explained by phylogeny.

Show code 
dat_model_phylo <- dat_model %>%
  mutate(
    species_phylo = Clements_name,
    species_nonphylo = scientific_name
  ) %>%
  filter(
    species_phylo %in% tree_pruned$tip.label
  )
