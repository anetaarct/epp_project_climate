8.1 Overview

This chapter defines the sensitivity analysis for the direct environmental predictor set. The same fixed effects are fitted in two versions: a mean-only model with a single global precision parameter (phi ~ 1) and a location- scale model where the environmental-geographic predictors and methodological controls are also included in the scale component.

Both models include methodological controls (nest_box, marker_type) and the same population, species, and phylogenetic random-effect structure as the main models.

8.2 Predictors

Model Mean component predictors Scale component
Mean-only tmp_cru_C_first_month_z, pre_cru_mm_first_month_log_z, dtr_cru_C_first_month_z, ndvi_first_month_median_30km_z, abs_latitude_z, distance_to_coast_z, nest_box, marker_type phi ~ 1
location-scale Same mean model phi ~ tmp_cru_C_first_month_z + pre_cru_mm_first_month_log_z + dtr_cru_C_first_month_z + ndvi_first_month_median_30km_z + abs_latitude_z + distance_to_coast_z + nest_box + marker_type

8.7 Predictive support and LOO diagnostics

LOO comparisons are used here to summarise support for the location-scale sensitivity model relative to the mean-only sensitivity model, and to compare the PCA sensitivity model with PC1 and PC2 against the version that also includes PC3. Higher expected log predictive density indicates better expected out-of-sample prediction. Pareto-k diagnostics are reported because high values indicate that LOO estimates should be interpreted cautiously.
